# Discipline - Personal Habit Tracker

A minimal, calm personal habit tracking web app built with clean, minimalist design.

## 🎯 Features

- **Daily Habit Tracking** — Log yes/no habits and numeric values (weight, wake-up time)
- **Multiple Views** — Daily, Prayer, Weekly, Monthly, and Stats tabs
- **Weight Tracking** — Visual weight loss trends with line charts
- **Habit Management** — Add, edit, delete, and archive habits
- **User Profile** — Track stats and manage preferences
- **Minimal Design** — Calm, distraction-free interface

## 🌐 Deploy to GitHub Pages (3 steps)

### Step 1: Create a GitHub Repository

1. Go to [github.com/new](https://github.com/new)
2. Repository name: `habit-tracker` (or any name)
3. Description: `Personal habit tracking app`
4. Make it **Public**
5. Click "Create repository"

### Step 2: Upload Files

1. Click **"Add file"** → **"Upload files"**
2. Download all 8 files from the project:
   - index.html
   - habit_tracker_mockup.html
   - habit_tracker_profile.html
   - habit_tracker_manage_habits_mockup.html
   - habit_tracker_habit_form.html
   - habit_tracker_stats.html
   - habit_tracker_login.html
   - Habit_Tracker_PRD.md
3. Drag & drop them into the upload box
4. Click **"Commit changes"**

### Step 3: Enable GitHub Pages

1. Go to repo **Settings** (top right)
2. Click **"Pages"** in the left sidebar
3. Under "Source", select **"main"** branch
4. Click **"Save"**
5. Wait 1-2 minutes for deployment
6. Your site will be live at: `https://yourusername.github.io/habit-tracker`
